# Autorio — Feirão Seminovos

Protótipo da landing page do Feirão Seminovos (Chevrolet) da concessionária Autorio.

- Página estática (HTML + CSS), com dois pequenos scripts: filtro de categorias e carrossel de fotos por veículo.
- Sem formulário: todos os CTAs levam ao WhatsApp via link Tintim.

## Estrutura
- `index.html` — a landing page
- `images/logo-feirao.*` — logo do Feirão Seminovos
- `images/veiculos/<veículo>/NN.webp` — fotos de cada veículo (ordem do carrossel)

Feito por 3ADS.
